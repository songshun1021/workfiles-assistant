# 工作资料助手 · macOS 本地 7 天应用与窗口线索

DeepSeek Harness 的 macOS 插件：**一次显式快捷键 → 说话 → 处理；只有歧义才追问。** 保留原有范围检索、接着纠正和安全打开。0.4.0 将 Office 三款建议扩展为用户可选的更多应用，并对另行同意的应用读取有限 Accessibility 窗口元数据；不是全盘监控或录屏记忆。

## 内测安装（朋友版）

当前固定版本 **0.5.1**，目标宿主 **DSH 0.2.2-rc.3 / macOS arm64**。这是本地链接安装的插件，不做通用分发包。

1. 把本仓库克隆到本地固定位置，**不要移动**：`git clone <repo> ~/Developer/workfiles-assistant`。
2. 安装依赖：在该目录执行 `pnpm install`。
3. 构建桌面语音组件（每台机器各自构建，产物在本机缓存里，不进仓库）：
   `pnpm run build:native`；随后可用 `node --test test/*.test.js` 自检。
4. 用 DSH 的插件管理器安装/启用该目录（本地 link 方式），刷新页面后侧栏底部出现「资料助手」。
5. 首次使用：全局快捷键 **⌘⇧Space** → 说话。若未准备本地识别模型，按提示手动准备后再录音；系统麦克风与辅助功能权限都由你本人在系统设置里授予。

已知限制（内测）：只在 macOS arm64 + DSH 0.2.2-rc.3 上验证；未接飞书/腾讯/MCP 连接器；不做 OCR/截屏；不同应用暴露的 Accessibility 元数据差异很大，取不到时只保留应用级线索。详见 [能力评估](<./MACOS_CAPABILITIES.md>) 与 [验收记录](<./VERIFICATION.md>)。

## 入口与日常使用

- **固定入口在 Harness 左侧栏底部“资料助手”**，没有聊天也能进入。输入框旁的语音／资料设置是备用入口，打开同一设置面板。
- **⌘⇧Space** 唤起语音小窗；说完停顿约 1.1 秒识别并处理。录音中再按快捷键为结束并提交。
- 准备／识别／处理时再按快捷键只查看同一个任务，不取消、不另起任务。停止用独立取消按钮；Esc 仅小窗获焦时有效。
- “不是这份”“第二个”沿用专用语音会话候选。追问后麦克风关闭，需要回答时再次显式触发。
- 完成／失败／取消即停止录音。短成功提示可收起，长结果、未找到和阅读交互保留。
- 无唤醒词、常驻菜单栏图标或悬浮启动器。Harness 需保持运行，完全退出后不采集、快捷键不响应；不设置开机启动。

例如：“找一下最近更新的课题报告 PPT，先列候选。”或在已开始记录后问：“刚才浏览器里出现过哪些资料？”

## 选择更多应用与窗口线索

**新用户默认关闭且不选任何软件。升级保留原有启用状态和所选软件；新增窗口标题／地址许可默认为空，不扩大同意、不回补历史。**

1. 进入侧栏底部“资料助手”。Word、PowerPoint、WPS 只是建议，不再是技术白名单。
2. 先运行你要记录的应用，再明确点击刷新运行中应用。此操作只列出当前运行、具有 GUI 的应用名称和标识，不读取窗口、网页或使用历史；不等于完整安装清单。最多选择 128 个应用，未在本次列表的旧选择仍保留。这里只保证保存所选标识，名称缓存不是永久通讯录：重启或来源缺失时可能显示 Bundle ID，刷新后再补名称。
3. 勾选允许记录的应用。暂停时选择不会自动开启；**如果记录已经开启，新选择会立即生效**。取消最后一个应用将安全暂停。切勿把一次刷新误解为选择或授权全部应用。
4. 基础线索是应用名称／标识和前台观察时间，不依赖 AX。原来批准的文件夹内本机文档仍沿用规范路径、类型和文件身份验证；不会因此扩大本机文件范围。
5. **窗口标题和 HTTPS 地址是额外的逐应用选择。** 它们可能包含私人文档名称和访问标识，只有你另外勾选的应用才可采；有界读取当前聚焦窗口，不读其它窗口、后台标签或正文。浏览器、飞书、腾讯文档等即使可选，也不保证其 AX 暴露了可用地址。
6. 在系统辅助功能设置中，由你为系统实际显示的读取进程手动授权，再重新检查；不要盲目授权其它进程。**AX 权限本身很广，并非只读；只读元数据是本插件的实现边界。** 不自动申请、授予或绕过权限。
7. 没有权限、属性不支持、树过深、焦点变化或超时，均只保留可靠的应用级线索；不能拿不到地址就猜一个。

### 保存什么，不保存什么

- 仅本地保存所选应用的名称／标识、观察时间；合规本机文档另存规范路径、名称、类别、文件修改时间；另行同意的窗口可保存标题和取得的规范 HTTPS 地址。
- HTTPS 地址去除查询参数与片段，不接受凭据、其它协议、IP、localhost 或 `.local` 等地址。因此某些依赖参数／片段的页面无法准确重开；不能保证所有企业内网页或本地开发站点可重开。
- **不读取正文、选中文字、控件值、按键、剪贴板、截图、音频、浏览器历史数据库或后台所有标签。** 不用 System Events，不做 AX 自动点击／输入，不设置辅助属性。只为取得当前 WebArea 地址进行角色级有界遍历，不向网页正文下钻。
- 没有 MCP、飞书／腾讯文档 API、浏览器扩展或云端连接器。本版没有通过这些来源查询历史、修改记录或正文。
- **滚动 7 天、最多 1000 条**，相邻相同线索去重。默认约 4 秒后再采下一次，执行耗时会延长间隔，短暂切换可能漏记；不是完整系统历史、精确使用次数或时长统计。
- “前台出现过”不证明阅读、编辑、保存或打开操作。`observedAt` 是观察时间，`modifiedAt` 是文件修改时间，不能据此声称谁修改了文档。
- Harness 运行期间，暂停记录也会清理过期数据；退出期间不运行，下一次加载先清理。不是系统守护进程。

## 暂停、清空与撤销

- 暂停记录停止新增，保留未过期记录。所选应用仍界定显式语音手势的短时当前便签；不想有按需读取时取消相应选择。
- 清空账本需要确认，删除账本和临时便签，不删除聊天／工具结果，不关闭文档，也不关闭后续记录开关。
- 取消应用选择会删除该应用的账本行；撤销窗口许可会清理该应用的窗口标题和地址、降级为应用线索，但原来获准的本机文档仍由文件夹范围控制。撤销文件夹会清除对应文档字段。
- **资料查找／打开与持续记录的暂停独立。** 暂停查找不暂停采集，暂停采集也不撤销合法查找范围；已记录网页的打开同样遵守查找／打开暂停。

## 查询与受控打开

- `workfiles_history` 默认 `detail:applications`，只返回应用名称、观察时间和有界汇总；在投影后才匹配条件，不通过标题或 URL 偷漏主题，也不进行文件元数据验证。
- 用户问文档／网页才使用 `documents/all`，包含另行同意的窗口线索。最多 20 条；本机候选重新验证文件范围／身份后才生成普通 `wf-` ID。
- 有可用地址的持久窗口行可变成当前 Session 的 `webCandidates`，通过已有 `workfiles_open` 的 `candidateId:wa-…` 请求默认浏览器打开。模型不能传任意 URL；打开前重验本地行、保留期、当前应用／窗口同意和本次候选。Owner 设置界面也调用同一个开链操作。
- 只有标题、临时便签或不安全／不完整链接时不授予持久开链 ID；清空、撤销、过期后旧 ID 无效。文件与网页候选分别由正常会话日志派生，主聊天和专用语音 Session 不混用。
- `open_requested` 只代表系统接受请求，不证明窗口出现、页面仍有效、已登录或有访问权限。取消不能可靠撤销 OS 已接受的打开请求。
- 想“看这个文件在哪个文件夹”时，助手用 `workfiles_open` 的 `revealInFinder: true` 在访达里选中该文件（等同于显示它所在文件夹）；它依然只接受本会话已有的 `wf-` 候选，不能打开任意文件夹或路径。网页线索没有本机文件夹，会被拒绝。
- 原有本机搜索仍先按主题再按真实修改时间；默认 PPT/PPTX，支持 Word、表格、PDF、文本等。需要时有限读取 PPTX/DOCX/UTF-8 内容，不为解析启动 Office，不修改／删除工作文档；不承诺宏或外部链接安全。

## 当前资料便签与模型边界

显式录音手势可在小窗抢焦点前读取所选应用当前线索。最多保留 2 分钟／16 份，仅内存、绑定实际语音 Session；结束、取消、清空、范围改变、过期、卸载立即释放。它不代替自动账本，不注入转写、隐藏提示或 IPC 状态，必须通过普通历史工具结果查询；临时 token 永不暴露。

**自动记录不调用模型 API。** 但本地账本／语音识别不代表整个任务离线：用户查询时相关名称、标题、链接、位置、时间、转写及按需文件片段可以进入普通 Harness 会话，按当前模型设置发送到服务。清空本地账本不撤回已发送内容。

专用语音 Agent 仍仅有 `workfiles_search / inspect / open / context / history` 五个工具，复用普通 Session，不复制开发聊天、不自建 LLM 循环。选择范围、记录开关、发现软件、清空、授权入口、改快捷键都仅供本机 Owner 界面；模型不能配置或授予权限。

## 第一次使用语音

- 查看小窗不开始录音、不申请麦克风。默认复用官方本地 SenseVoice；若未准备，由你点击准备下载 INT8 权重约 239 MB 及运行时／VAD 资产。
- 准备结束不自动开麦；再次明确开始，由你处理麦克风权限。最多录音 20 秒，约 8 秒无讲话退出，仅提交最终完整音频。
- 音频在内存中，不另存录音、不自动回退云端。追问只用已有本地中文声音；没有合适声音就显示文字。键盘输入回退会停麦，收起键盘不会自动重开。
- 快捷键更改必须以系统实际注册成功为准；冲突或未就绪显示失败，不把配置已保存等同于物理快捷键已验证。

## 实现、构建与验证边界

当前 **0.4.0／DSH 0.2.2-rc.3／macOS arm64**。公开 Cordis／Typert／StorageDomain 接口；不增加 HTTP 服务、不修改或重签原 App。旧 `local_workfiles_activity` v1 数据用向后兼容解码器读取，不重置旧数据，新窗口许可补为空。

原生采集具有节点／深度／时间／输出／进程退出预算；不会失败后退回全树或 OCR。语音小窗自有 Electron 组件保留宿主／副本／11 个冻结资源哈希校验；只有相关资源或宿主变动才需要在批准缓存中重建，不通过版本豁免绕过。原 App 不改／不重签。

源码为本地链接安装，**不要移动或删除本项目目录**（DSH 记录的是这个绝对路径；要换位置就 `git clone` 到新位置后重新 `link:` 安装）。参考 [能力评估](<./MACOS_CAPABILITIES.md>)、[语音协议](<./VOICE_PROTOCOL.md>)、[原生说明](<./native/README.md>)、[开源选择](<./OPEN_SOURCE.md>)、[第三方声明](<./THIRD_PARTY_NOTICES.md>)、[验收记录](<./VERIFICATION.md>)。

单元、假进程、纯 VM JXA、接口注册与签名检查，均不等于实际 macOS 桥接、窗口／网页兼容、AX 权限、物理快捷键、麦克风或已认证 GUI 点击验收；实测与人工剩余项分别记录，不把模拟通过冒充实机通过。

## 项目结构与开发

自包含工程：插件源码、原生组件源码、源码级测试和设计稿都在同一个仓库里。

| 路径 | 内容 |
| --- | --- |
| `index.js` `client.js` `voice.js` `lib/` | Harness 插件本体（Host 侧、Client 侧、语音协调、语义校正） |
| `voice-ui/` | 原生语音小窗页面（`index.html` / `panel.js` / `panel.css` / `audio.js` / `view-state.js`） |
| `native/` | 小窗的 Electron 组件源码、`motion.mjs` 动画几何、构建脚本与线路协议 |
| `test/` | 纯 Node 测试，不需要 GUI、麦克风或真实 DSH 会话 |
| `locale/` `cordis.patch.yml` | 文案与插件补丁清单 |
| `design/` | 收敛后的液体玻璃面板设计稿 `panel-flow-blue.html` 与历史概念稿 |
| `.native/` | 本机构建记录（不入库，每台机器各自生成） |

常用命令：

```sh
pnpm run check            # 逐文件语法检查
node --test 'test/*.test.js'
pnpm run build:native     # 构建桌面语音组件到 ~/Library/Caches/DeepSeekHarness/WorkfilesVoice
```

**改动 `voice-ui/` 或 `native/` 之后必须重新 `pnpm run build:native`。** 小窗启动前会校验 11 个冻结资源的哈希：源码改了而组件没重建时，快捷键会静默失效并提示「语音界面源码已改变」——这是刻意的闸门，不是故障。
